## How to Use

### 1. Start Backend
```bash
cd backend
python app.py
```
✓ Running on http://localhost:5000

### 2. Start Frontend  
```bash
cd frontend
npm run dev
```
✓ Running on http://localhost:5173 or :5176

### 3. Register User
- Go to http://localhost:5173/register
- Enter name, email, password
- ✓ User created in MongoDB
- ✓ Wallet auto-generated on Sepolia testnet
- Redirected to Dashboard

### 4. View Wallet Info
- After login, check top right header
- Shows: Name, Email, Wallet Address (truncated), & Wallet Status
- Example: `✓ Wallet Ready` (means on Sepolia)

### 5. Book Flight
- Go to "Booking" page
- Select flight + seat
- Click "Book This Flight"
- ✓ Booking saved to MongoDB
- ✓ Compensation calculated
- Booking appears in "Your Bookings"

### 6. Test Delay Modification
- Go to "Testing" page (admin)
- Select any booking
- Click "Update Delay"
- Change delay_minutes (e.g., 120, 300, 400)
- Click "Save"
- ✓ Delay updated in MongoDB
- ✓ Compensation recalculated automatically

### 7. Claim Compensation
- Go to "Compensate" page
- Select booking with available FLY
- Choose "FLY Tokens" or "Voucher"
- Click "Claim"
- ✓ Blockchain transaction initiated (or fallback)
- ✓ Booking marked as claimed

## Data Flow

```
User Registration
  ↓ POST /api/auth/register
  ↓ Create wallet (eth_account library)
  ↓ Store in MongoDB users collection
  ↓ Return JWT + user object with address & wallet_created=true

Display User Info
  ↓ Layout shows account.address (wallet) + account.wallet_created
  ↓ Shows wallet address truncated format

Book Flight
  ↓ POST /api/bookings/create
  ↓ Calculate compensation based on delay
  ↓ Store in MongoDB bookings collection
  ↓ Frontend refreshes from GET /api/bookings/user/<id>

Update Delay (Testing)
  ↓ POST /api/test/update-delay
  ↓ Recalculate compensation
  ↓ Update booking in MongoDB
  ↓ Return new compensation values

Claim Compensation
  ↓ POST /api/bookings/compensation/<booking_id>
  ↓ Attempt blockchain transfer
  ↓ Mark booking as compensation_claimed=true
  ↓ Update user fly_balance
```

## Endpoints Available

### Auth
- POST /api/auth/register - Create user with wallet
- POST /api/auth/login - Login user  

### Bookings
- POST /api/bookings/create - Create booking
- GET /api/bookings/user/<id> - Get user bookings
- POST /api/bookings/compensation/<id> - Claim compensation

### Testing
- POST /api/test/update-delay - Update delay
- GET /api/test/all-bookings - All bookings
- GET /api/test/users - All users  
- GET /api/test/wallet-balance/<addr> - Check balance
