02 // Compensation Logic Flow
01
USER SELECTS FLIGHT
Passenger picks delayed booking from dashboard
02
VALIDATE DELAY ≥ 2 HOURS
System checks delay_minutes against EU261 threshold
03
CALCULATE ETH AMOUNT
2–3 hrs → 0.010 ETH (~$20) 3–4 hrs → 0.015 ETH (~$30) 4+ hrs → 0.020 ETH (~$40) 24+ hrs → 0.050 ETH (~$100)
04
CHECK DEPLOYER BALANCE
Verify 0xfD03Df67... has sufficient ETH
05
BUILD & SIGN TRANSACTION
Sign with Private Key · Create Raw TX
06
SEND TO BLOCKCHAIN
Broadcast signed TX to Sepolia network
07
MARK BOOKING CLAIMED
Update MongoDB: compensation_claimed = true
08
RETURN TX HASH TO USER
Display hash · Verify on Etherscan

04 // EU261 Compensation Tiers
Delay Duration ETH Amount USD Equivalent EU261 Classification

3 – 4 hours 0.015 ETH ~$30 Medium delay — standard comp
4+ hours 0.020 ETH ~$40 Long delay — full comp
24+ hours 0.050 ETH ~$100 Cancellation / extreme delay

06 // MongoDB Booking Schema
{
  _id: ObjectId,         // Primary key (auto-generated)
  user_id: String,       // Reference to Users collection
  flight_number: String,  // e.g. "BA2490"
  delay_minutes: Number,  // EU261 threshold check
  status: String,        // "delayed" | "completed" | "cancelled"
  compensation: {
eth_amount: Number,   // 0.010 / 0.015 / 0.020 / 0.050
usd_value: Number,    // Live price from CoinGecko
description: String,  // Human-readable tier label
type: String       // Classification key
  },
  compensation_claimed: Boolean,  // Prevents double-claim
  tx_hash: String  // Optional · set after blockchain TX
  created_at: Date   // ISO timestamp
}
